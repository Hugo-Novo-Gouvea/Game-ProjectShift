# Game-ProjectShift

Jogo em desenvolvimento para a **[GitHub Game Off 2026](https://itch.io/jam/game-off-2026)**.

## A Jam

| | |
|---|---|
| **Organização** | GitHub |
| **Tema** | **SHIFT** |
| **Período** | 1 de novembro – 1 de dezembro de 2026 (13:37 PST) |
| **Votação** | até 1 de janeiro de 2027 |
| **Categorias** | Overall, Gameplay, Graphics, Audio, Innovation, Theme Interpretation |

Regras principais:
- Qualquer linguagem, engine ou biblioteca é permitida.
- O código-fonte precisa estar em um **repositório público no GitHub** (este aqui).
- O jogo deve ser enviado no itch.io antes do prazo.
